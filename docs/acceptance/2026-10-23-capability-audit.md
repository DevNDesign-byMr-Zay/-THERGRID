## Highest meaningful gaps and measurable acceptance

1. **Unified hover identity:** add read-only hover picking across renderer contract/adapters plus `SpatialViewport.tsx`; reuse dossier identity/source formatting. Acceptance: move over real mapped building, road, grid feature and aircraft → correct name/type/source age; leaving hides tooltip; hover never alters selected dossier, camera or pinned set; tooltip stays within viewport.
2. **GRID has no dedicated navigation effect:** wire existing grid-resilience preset from GRID navigation, expose mapped energy layers and useful selected-network operations. Acceptance: pressing GRID from any preset makes real energy geometry visible; one mapped line/substation opens source/operator/voltage details; returning restores prior view if provided. Label derived topology and scenarios explicitly.
3. **Observed aircraft follow:** add tracked aircraft identity and camera updates from successive fixes, release when unavailable/stale or on operator cancel. Acceptance: replay two actual captured provider fixes under test plus successful live feed run; selected model moves and camera follows without fabricated extrapolation; metadata exactly matches source; Escape/return ends follow.
4. **Road traffic is not implemented:** add a licensed/authorized road observation adapter only when available, then provenance-preserving segments/incidents UI; otherwise show unavailable honestly. Acceptance: source corridor ID/geometry/speed or incident/time appears in map and inspection with same returned values; no synthetic moving cars qualify.
5. **Radar visual redesign:** retain manifest/layer engine; replace dominating timeline with compact radar geography/scope, decorative sweep disclosure and provider-calibrated color legend. Acceptance: real returned RainViewer timestamps advance geographically aligned raster frames; stalled/error tiles reported; observed/stale/forecast remain distinct.
6. **Electrical modeling boundary:** preserve true OSM geometry while adding a scoped connectivity/asset scenario model using explicitly supported connections, not nearest-neighbor inference. Acceptance: selected asset disruption has reproducible input/output and explains unknown connectivity; no EIA aggregate mislabeled as line load.
7. **Visual and settings acceptance:** implement label/camera/refresh controls, then capture real NYC/London/Tokyo plus all-eight-city browser comparisons and packaged fresh-start evidence. Baseline screenshot filenames or fixture tests alone do not establish requested visual quality.
