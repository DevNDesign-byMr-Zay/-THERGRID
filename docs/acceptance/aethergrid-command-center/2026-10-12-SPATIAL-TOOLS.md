# Functional spatial tools acceptance — 12 October 2026

This branch continues the canonical React/Cesium application and stacks on the operational timeline PR. It changes frontend geometry, interaction and local operator views. It does not change backend providers, authentication services, quantum integration or release packaging.

## Verified behavior

- Cesium source footprints have batched roof/base/wall edges. Wireframe hides fill; holographic changes real geometry alpha. Independent layer opacity reaches the active renderer, including opacity zero. Mapped roof/body picks preserve source identity; selection and replaced primitive teardown have regression coverage.
- Native WebGL keeps its explicitly projected wireframe presentation. It renders layer opacity and geographic surface picking; the persistent status says that terrain is unavailable. Full limitations remain in Renderer tools.
- Operator scenarios replay continuously only inside an explicit, positive, matching-model interval. Source forecasts replay exact returned samples. Saved endpoints absent from new coverage remain unavailable until an explicit full-coverage reset. Sessions retain their embedded matching scenario independently of the saved-model collection.
- Picked polygons produce local horizontal area in m² and geodesic perimeter. Self-intersections, invalid coordinates, duplicate vertices, polar coordinates and polygons beyond a 20 km local radius are withheld. The result does not represent terrain surface area. Distance measurement remains available separately.
- Scene JSON includes the active camera, view parameters, layer visibility/opacity, frame/range, selected source references and whitelisted receipts. It excludes arbitrary selection properties, runtime configuration and profile fields. Unsupported legacy camera access yields null. The native snapshot describes projected view parameters.
- Comparison cards keep independent A/B timestamps and numerical receipts. Aligned source-backed forecasts retain FORECAST or STALE weather state. Historical and scenario frames do not reuse current observations. Mixed source states cannot become verified measured change. Frame switching uses one renderer and revalidates forecast coverage without moving an unavailable saved cursor.
