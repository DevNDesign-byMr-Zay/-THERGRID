# Module size debt

The default ceiling is 500 nonblank, noncomment code lines, measured from syntax tokens. `npm run lint` scans maintained JavaScript and TypeScript source and tests; ESLint also checks maintained JavaScript. These finite exceptions cannot grow. Extract one cohesive responsibility with behavioral regression tests, lower its ceiling, and retire it at 500 or below.

Owner for every row: **DevNDesign-byMr-Zay**, the repository maintainer. Tracking: [#232](https://github.com/DevNDesign-byMr-Zay/-THERGRID/issues/232). Each exception is temporary and has its own rationale and intended resolution below.

The backend entry point is now 199 code lines, with authorization, observation persistence and route families under `server/http/`. The native renderer is now 498 code lines, with pure frame/environment/geometry and draw backends alongside it. Neither needs a size exception. The release-readiness entry point decreased from 905 to 745 lines. The legacy shell decreased from 3462 to 2794 code lines after building geometry, settings DOM bindings and the mapped city mesh loader moved into classic-script companions. The React shell decreased from 2132 to 1938 code lines after current city sources, camera-driven tile streaming and the weather timeline moved into separate hooks. The transit registry retired its exception after extracting its GTFS-Realtime decoder and preserving the registry export. The scenario composer retired its exception after moving baseline, delta and visual summaries into a dedicated component.

The remaining classic and React shell work requires preserving browser initialization, scene identity and cancellation behavior.

Native draw-command tests characterize geometry, opacity, selection, weather, camera cancellation, reduced motion and per-frame buffer deletion. They do not establish hardware GPU acceleration, context-loss recovery or GPU memory behavior. The native baseline's missing context-loss handler and explicit program deletion remain tracked in #232.

Cesium constant graphics properties now update in place through `constant-property.ts`: identical values do not dirty the entity every clock tick. Source values, temporal visibility, pulses, selection and opacity remain tested. The large overlay module still has the separate extraction work above.
