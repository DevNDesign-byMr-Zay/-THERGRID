# VÆLON × SOLVÆR Handoff

THERGRID remains the authoritative state, simulation, provenance, and safety boundary.

## VÆLON

VÆLON owns advisory intelligence routing, experiment interpretation, spatial explanation, and renderer-neutral presentation contracts. VÆLON outputs must carry model identity, capability, status, and fallback evidence.

## SOLVÆR

SOLVÆR joins as an advanced solver/analysis partner. It must not bypass validation or directly mutate authoritative state. Solver results should be comparable with the classical reference and quantum-inspired baselines.

## Required evidence envelope

Every advanced result should identify:

- experiment fingerprint
- input snapshot identity
- constraint set
- model and version
- solver and version
- seed, when stochastic
- objective and feasibility metrics
- runtime/timeout state
- fallback identity, if activated
- provenance links

## Evaluation track

1. Run the same deterministic fixtures through classical, quantum-inspired, and SOLVÆR implementations.
2. Compare objective quality, constraint violations, runtime, reproducibility, and failure behavior.
3. Preserve all candidate results even when a fallback wins.
4. Promote only validated proposals into downstream simulation.
5. Keep holographic/spatial clients downstream of the validated decision receipt.

## Design principle

Advanced intelligence earns authority through evidence; sophistication alone is never an authorization boundary.
