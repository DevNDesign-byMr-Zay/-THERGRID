# ÆTHERGRID v0.3.5

Version 0.3.5 improves native WebGL lifecycle ownership, extracts source-preserving legacy building geometry and retains globe configuration when WebGL is unavailable. It preserves renderer APIs, spatial provenance, initialization order, camera/time/layer/selection behavior, agents and solver paths.

Publication requires reviewed integration and the protected exact-main checks. [Historical canonical evidence](https://github.com/DevNDesign-byMr-Zay/-THERGRID/actions/runs/41957050578) for baseline `34c18d17783e085f90bbebf7eea1b11483cbb5c3` does not certify v0.3.5.

## Quantum scope and remaining limits

Canonical acceptance defaults to the bounded `local-simulator` software quantum profile, exercising the maintained sampler/estimator while keeping all other live-provider gates. Real Qiskit Aer has a separate required workflow. Strict authenticated IBM discovery remains an opt-in protected profile. IBM is unverified in the software profile; no hardware submission, execution or certification is claimed. D-Wave remains on hold. Physical GPU performance, actual user Windows-device acceptance, deployment and operational authority remain separate requirements. Advisory results never authorize physical actuation.

## Local GUI use

1. Download and extract `aethergrid-functional-app.zip`.
2. Open its root `index.html` for direct-open browser operation. Optional service-backed features require the full runtime.
3. To start the full runtime on Windows, use `START-AETHERGRID.cmd` or `START-AETHERGRID.ps1` in the extracted directory with an allowed Node.js 22 process. Configure optional provider credentials in the ignored runtime environment. HTML cannot silently start protected services, and downloaded archives do not contain CI secrets.

## Verify downloaded evidence

The release includes `release-commit.txt`, `release-manifest.json`, `sbom.cdx.json` and `release-artifacts.sha256`. Check the manifest/tag/commit alignment and all SHA-256 digests before launch. On a shell with `sha256sum`, `sha256sum --check release-artifacts.sha256` expects the layout recorded in that file. If GitHub downloaded all assets into one flat directory, move `aethergrid-functional-app.zip` and `aethergrid-operator-console.zip` into a `dist/` subdirectory first; leave the evidence files at the top level. A flattened layout does not satisfy the original relative checksum paths unchanged. On PowerShell, `Get-FileHash -Algorithm SHA256` can verify each asset against its recorded digest and path.
